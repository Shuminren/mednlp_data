# mednlp_data

Frozen reproducibility package for the MedNLP-Hub.

## Contents

- `curated_dataset/`: frozen curated MedNLP-Hub dataset.
- `benchmark_queries/`: benchmark query scenarios, candidate results, and adjudicated scoring workbook.
- `statistical_analysis_code/`: main statistical analysis code for round-level performance and consistency.
- `statistical_outputs/`: regenerated statistical output workbook.
- `semantic_retrieval_settings/`: semantic retrieval configuration notes.
